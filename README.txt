FlirtDesk API — deploy to Vercel (free)
======================================

This folder is a complete, self-contained Vercel project. It has no
dependencies and no build step, so it deploys on the Vercel free plan.

What it contains
----------------
  api/replies.js   the drafting endpoint (POST /api/replies)
  api/_rules.js    the ABC Manual 9.0 rules: system prompt + draft checker
  public/index.html a test page served at /
  package.json     marks the code as ESM

Step 1 — get a free Google Gemini API key
-----------------------------------------
  1. Go to https://aistudio.google.com/apikey
  2. Sign in with a Google account and click "Create API key"
  3. Copy the key (it starts with AIza...)

The free tier covers normal chat drafting. No card required.

Step 2 — deploy this folder
---------------------------
Easiest (no tools to install):
  1. Create a new GitHub repo and upload the CONTENTS of this folder
     (so api/ and public/ sit at the repo root, not inside vercel-app/).
  2. On vercel.com click "Add New… > Project" and import that repo.
  3. Framework Preset: "Other". Leave build/output settings empty.
  4. Before deploying, open "Environment Variables" and add:
       Name:  GEMINI_API_KEY
       Value: your AIza... key
  5. Deploy.

With the Vercel CLI instead:
     cd this-folder
     npx vercel        # follow prompts, choose "Other"
     npx vercel env add GEMINI_API_KEY   # paste the key, select all environments
     npx vercel --prod

Step 3 — check it works
-----------------------
Open your deployment URL in a browser. You should see the FlirtDesk test
page (not a 404). Paste a short conversation and click "Draft a reply".

If you see "GEMINI_API_KEY is not set", the variable is missing — add it in
Vercel > Project > Settings > Environment Variables, then redeploy.

Step 4 — point the extension at it
----------------------------------
  1. Load the extension in Orbita (chrome://extensions > Developer mode >
     Load unpacked, or install the zip after unzipping it).
  2. Right-click the FlirtDesk icon > Options (or Extensions > FlirtDesk >
     Details > Extension options).
  3. Paste your deployment URL, e.g.
       https://your-project.vercel.app
     and click Save. The extension adds /api/replies itself.

That's it. From then on every draft is generated by Google's free tier
through your own Vercel deployment. Nothing runs on, or is billed by,
Lovable.

Notes
-----
* Free Gemini keys are rate limited per minute. If you click very fast you
  may see "Google rate limited the free tier" — wait a few seconds.
* The endpoint is public. Anyone who learns your URL could use your Gemini
  quota. Don't post the URL publicly.
* The rules engine is in api/_rules.js. Edit the FLAGGED list there to add
  or remove banned words, then redeploy.
